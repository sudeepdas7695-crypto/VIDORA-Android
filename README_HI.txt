VIDORA Android starter project

महत्वपूर्ण:
- यह शुरुआती Android ऐप प्रोजेक्ट है, तैयार APK नहीं।
- अभी इसमें VIDORA का डेमो Home UI है। असली वीडियो अपलोड, लॉगिन, लाइक/कमेंट, लाइव स्ट्रीम और सर्वर के लिए backend/database तथा video hosting जोड़नी होगी।

APK बनाने के लिए:
1. कंप्यूटर पर Android Studio इंस्टॉल करें।
2. इस ZIP को Extract करें।
3. Android Studio में 'Open' चुनकर VIDORA_Android_Project फ़ोल्डर खोलें।
4. Gradle Sync पूरा होने दें और जरूरत पड़ने पर Android SDK 35 इंस्टॉल करें।
5. Build > Build Bundle(s) / APK(s) > Build APK(s) चुनें।
6. APK आम तौर पर app/build/outputs/apk/debug/app-debug.apk में मिलेगा।

फोन पर इंस्टॉल करने से पहले APK केवल अपने भरोसेमंद कंप्यूटर से बनाएं। यह प्रोजेक्ट किसी आधिकारिक YouTube ऐप से संबद्ध नहीं है।
